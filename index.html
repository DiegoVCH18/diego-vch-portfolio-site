Banca · Mibanco

Reportería de capacitación sin consolidación manual

Problema
El seguimiento académico y de productividad de la escuela de formación se consolidaba a mano cada mes, con indicadores difíciles de rastrear.

Educación superior · CERTUS

Modelo de permanencia estudiantil con machine learning

Problema
El riesgo de desaprobación o deserción se detectaba cuando ya era tarde para intervenir.
Qué hice
Construí un pipeline de limpieza, análisis exploratorio y modelos (Random Forest, XGBoost y CatBoost) sobre unos 7,000 registros por ciclo, que predice el riesgo desde la Evaluación 1. Lo publiqué como aplicación para los docentes.
Resultado
Precisión de 90 % en la predicción de riesgo académico
Stack
  • Python
  • pandas
  • scikit-learn
  • XGBoost
  • CatBoost
  • Hugging Face

Impacto social · Asociación sin fines de lucro

Sistema integrado de datos para programas sociales

Problema
Los registros de beneficiarios y la programación de actividades vivían en matrices separadas por unidad de negocio, con duplicados y sin control de acceso.
Qué hice
Desarrollé un portal web con fichas de registro, una API y una base de datos con roles y seguridad por fila. Consolidé y depuré las matrices, automaticé el tracker de proyectos y armé los tableros ejecutivos para la dirección.
Resultado
9 matrices de programas unificadas en una sola base con acceso por roles
Stack
  • PostgreSQL
  • API REST
  • Power Query
  • Power BI

Cómo trabajo

Un proceso corto y sin sorpresas

  1. Diagnóstico

    Revisamos tus fuentes, procesos y la decisión de negocio que necesitas resolver.

  2. Diseño

    Acordamos métricas, arquitectura de datos y un entregable concreto con fecha.

  3. Construcción

    Desarrollo por sprints; validas el avance en cada entrega.

  4. Entrega y capacitación

    Documento la solución y capacito a tu equipo para operarla solo.
